Reimagining the agent portal

I designed and built a working prototype of a reimagined agent portal: one place where a real estate agent can see goals and capping progress, understand revenue share, run transactions, grow through mentorship and get help from an AI assistant.

My role

I designed and built the prototype end to end in Lovable. I owned the product thinking and the full UX: information architecture, user flows, interaction and visual design, and the AI-assisted build that turned the designs into a clickable, stateful app I could demo live.

What I did

  • Mapped the portal into three clear areas: My Desk, Business & Growth, Resources
  • Designed 71 screens and states, including drawers, dialogs, filters and empty states
  • Defined reusable patterns: data tables, detail drawers, KPI cards, tabs
  • Built a scenario switcher so one prototype can tell many user stories
  • Prototyped the experience in Lovable with AI-assisted development

The problem

An agent’s working day spans many questions: How close am I to my goals and my cap? What have I earned in revenue share, and when will I be paid? Which deal needs my attention? Who is my mentor? Where do I find a document or get help?

When those answers live in separate tools and dense tables, agents spend effort finding information instead of acting on it. I wanted to show what a single, personal and consistent portal could feel like.

Goals

  • Personal: a Home that reflects each agent’s own goals and progress
  • Legible: make complex earnings and organization data easy to read
  • Actionable: surface what needs attention next
  • Consistent: one set of patterns across every area
  • Demo-ready: show many user states without separate accounts

Key design decisions

Each area solves a specific job for the agent. Click any screen to open it in the interactive walkthrough.

01

A personalized Home that answers “where do I stand?”

I made Home a mission-control view: three goal KPIs with progress against the agent’s own targets, Weekly Quests for small habits, and the capping ring front and center. Goals and quests are edited in focused side drawers so the agent never leaves the page.

Customize mode lets each agent reorder and hide cards, with a clear Done / Reset layout, so the dashboard adapts to how they work.

02

Capping progress as a moment, not a number

Capping is one of the most meaningful milestones for an agent, so I designed it as a recurring visual thread: the capping ring on Home, a year-by-year capping history timeline on the Agent dashboard, and a CAP REACHED celebration state that turns goals green and adds goal-reached badges.

03

Making RevShare legible: payouts, levels and the org tree

RevShare data is dense and hierarchical. I split it into clear jobs: a dashboard with YTD earnings, a level ladder (4 of 6 unlocked) and payout status cards; a Get Paid Now flow that shows the fee and the total to deposit before any commitment, in four explicit steps; Financials for unpaid, periodic and batch history.

For the organization, I designed a drill-down Organization Tree with a depth breadcrumb, ranked agent cards and “Drill in / Up one level”, instead of an unreadable full tree.

04

Agent Desk: one workspace per transaction

Agent Desk starts with the active pipeline and a Needs your attention list so the next action is obvious. Each transaction opens into a workspace with persistent key facts (agent, buyer, expected close, days on market, price) and tabs for Overview, Contacts, Commission, Checklist, Documents, Activity and Comments, so everything about a deal lives in one place.

05

Mentor Program flows for every role and state

Mentorship has many states, so I designed it as a set of journeys: a new agent sees a Find Your Mentor card with a countdown, compares mentor cards and profiles, or lets the system choose. Agents can apply to become mentors through a prefilled multi-step application, and certified mentors get a dashboard for mentees, pending requests (Accept / Decline) and their own public profile. Mentees see their mentor, training materials and progress.

06

Notifications with context

Notifications became a full page with an Activity Feed and a Recognition tab, quick date and type filters, and a detail drawer that explains the event in context (capping details, ICON status, top transaction). Recognition items include a send-a-gift action to encourage celebrating peers.

07

Mira, an AI assistant woven into the portal

Mira is a floating assistant available on every screen. It offers suggested prompts (GCI trends, listing velocity, active pipeline), keeps chat history, and answers with chart insight cards that can be pinned to the dashboard. The same assistant powers AI chat support in Contact eXpert Care, so help and insights share one entry point.

08

Scenario-driven Demo Config for stakeholder demos

To demo realistic journeys without fake accounts, I built a Demo Configuration panel into the account menu: mentor modes, capping scenarios (including CAP REACHED), ICON toggles, country and FLQA states. Switching a scenario updates the live UI, and a sidebar Demo Toggles menu covers the most common switches during a walkthrough.

09

A consistent table system

Much of the portal is tabular, so I standardized one data-table pattern: search and filter chips, a column manager, Save View, Download, per-column search, pagination, and row click to open a detail drawer. Once agents learn it on one page, it works the same on State Mentors, Production Details, Team Reconciliation, Revenue Share Group and My Mentees.

Reflection

Building the prototype myself changed how I design. Working in Lovable with AI assistance let me move from idea to a working, stateful experience quickly, and test interactions like drawers, drill-downs and multi-step flows as real behavior instead of static frames.

The Demo Config turned out to be one of the most useful design tools in the project: one prototype can tell the story of a new agent looking for a mentor, an agent who just capped, and a certified mentor, live in the same session.

What’s next

  • Usability testing with agents on Home, RevShare and Agent Desk
  • Complete the remaining routes (Events Calendar, Tools, Knowledge Base, Downloads)
  • Mobile layouts for the most frequent on-the-go tasks
  • Accessibility review of color, contrast and keyboard flows in charts and tables
  • Deeper Mira capabilities grounded in the agent’s own data
